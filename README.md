# Hozu UI

The official components of [Hozu](https://hozu.org): buttons, forms, tables, dialogs and page states in two themes,
Grain and Joinery. The kit is copied into your app's `ui/` folder, so the source is yours and your AI's to edit, and
Hozu checks every change to it. See them at **[ui.hozu.org](https://ui.hozu.org)**.

Components: Badge, Button, LinkButton, Card, Dialog, Field, Icon, Input, DropdownMenu, MenuItem, Metric, NavBar,
NavLink, Pagination, PageHeader, EmptyState, Problem, Notice, Table, Th, Td, Tr.

## Install
Hozu UI needs Hozu 1.0 (the candidate is on npm's `next` tag).

A new app (`create-hozu` asks whether to add the kit; `--ui` says yes):

```sh
npx create-hozu@next my-app --ui
```

An app you already have:

```sh
npx -p @hozu/cli@next hozu migrate        # on Hozu 0.31 or older
npm install -D @hozu/ui-kit
npx hozu add kit ui --from official       # or one: npx hozu add component ui Button --from official
```

`ui/kit.lock.json` records what was copied. `npx hozu add kit ui --sync` updates the files you did not change and
lists the ones you did. `npx hozu docs ui` tells you and your agent which component fits which need.

## With Hozu DevTools
Run `npx hozu dev` and open Assets: Hozu UI comes first, with every variant and composed examples. Drag a component
onto your page, write what it is for, and hand the request to your agent, which installs what is missing, places it
and runs `hozu check`.

## This repository
- `kit/`: the kit source; `catalog.json` (generated by `npm run catalog`) tells Hozu what each file holds.
- `site/`: ui.hozu.org, built with Hozu.
- `docs/`: `ui.md` (shipped, printed by `hozu docs ui`), and the research, decisions and spikes behind the kit.
- `tools/`, `scripts/`, `spike/`: install and contrast checks, Lucide extraction, the redone trial screens.

A version tag publishes the package to npm after the owner approves the `npm` environment.
