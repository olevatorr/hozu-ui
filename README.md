# Hozu UI

Research and design for the official UI kit of [Hozu](https://hozu.org) (`@hozu/ui-kit`, reserved in ADR 0045).

- `docs/` — research notes and the design proposal.
- Status: research. Nothing here is published, and the framework repository is not changed from here.

## Documents
- [docs/proposal.md](docs/proposal.md): the kit proposal (ideas, architecture, components, visual direction, framework changes, questions).
- [docs/research.md](docs/research.md): findings with sources.
- [docs/spikes.md](docs/spikes.md): experiments on Hozu 0.26.4.
- [docs/decisions.md](docs/decisions.md): the owner's decisions, licensing.
- [docs/spike-1.md](docs/spike-1.md): the kit on two real trial screens, with measurements and screenshots.
- [docs/spike-2.md](docs/spike-2.md): spike 1's checks re-run on Hozu 0.27.0.
- `kit/`: the kit source (themes Grain and Joinery, 23 components); `tools/`: install and contrast scripts; `scripts/`: Lucide extraction and the icon similarity check; `spike/`: the redone screens.
